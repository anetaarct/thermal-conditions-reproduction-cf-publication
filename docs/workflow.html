SMHI download code (new recipe; not the archived downloader)

SMHI source and station catalogue. This example saves fresh archives separately; it does not replace the publication snapshot.

stations <- c(Hoburg = 68550, Hoburg_A = 68560)
dir.create("data_raw/smhi", recursive = TRUE, showWarnings = FALSE)
for (name in names(stations)) {
  url <- sprintf(paste0(
    "https://opendata-download-metobs.smhi.se/api/version/1.0/",
    "parameter/2/station/%s/period/corrected-archive/data.csv"
  ), stations[[name]])
  download.file(url, file.path("data_raw/smhi", paste0(name, ".csv")),
                mode = "wb")
}

Check the saved inputs

The following check rebuilds all 46 annual means from the daily snapshot (43 days per year).

Show original code: 00_check_public_inputs.R 
R/00_check_public_inputs.R
# New public-input check; not the historical download/cleaning script.
# Run from the publication repository root.
library(readr)
library(dplyr)
daily <- read_csv("data_derived/smhi_hoburg_daily_temperature.csv", show_col_types = FALSE)
annual <- read_csv("data_derived/annual_main_window_temperature.csv", show_col_types = FALSE)
phenology <- read_csv("data_derived/annual_raw_median_laying_date.csv", show_col_types = FALSE)
stopifnot(nrow(daily) == 16802L, !anyDuplicated(daily$date))
stopifnot(nrow(annual) == 46L, all(annual$n_days == 43L))
stopifnot(nrow(phenology) == 45L, !2020L %in% phenology$year)
rebuilt <- daily |>
  filter(format(date, "%m-%d") >= "03-26", format(date, "%m-%d") <= "05-07") |>
  group_by(year) |>
  summarise(temp_mean = mean(temperature), n_days = n(), .groups = "drop")
check <- inner_join(annual, rebuilt, by = "year", suffix = c("_saved", "_rebuilt"))
stopifnot(nrow(check) == 46L, all(check$n_days_rebuilt == 43L))
stopifnot(max(abs(check$temp_mean_saved - check$temp_mean_rebuilt)) < 1e-10)
print(check)
Daily records: 16,802; unique dates: 16,802
Annual means: 46; days in each window: 43
Rebuilt means agree with the saved CSV within 1e-10 °C.

The same checks were independently evaluated against the CSV files when preparing this site; R chunks are displayed without execution.

Software versions

The final reproductive-model documentation records R 4.6.1 and glmmTMB 1.1.14. Session logs are not included, so these versions are reported from that documentation; the original sliding-window R version is unconfirmed. Paths mentioning R 4.5 identify library folders, not an independently verified runtime.

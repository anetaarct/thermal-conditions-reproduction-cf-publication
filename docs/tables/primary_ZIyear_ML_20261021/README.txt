Final reproductive results use maximum likelihood in glmmTMB. ZIyear_* tables contain the final zero-inflated beta-binomial fit with year random effects in extra-zero probability. model_comparison.csv, fixed_effects.csv and simulation_checks.csv also retain the simpler constant-extra-zero ML comparator. Curves are conditional reference predictions with all random effects zero. Intervals are Wald or joint asymptotic 95% CIs; plug-in simulation envelopes omit parameter uncertainty. Individual records and fitted objects are not public.
